# MHAA Reset Contract

Models a recorded set of reset causes and optional operations to acknowledge the record or request a reset. Cause capture and clearing share the same source.

Expose `ResetInfo` where causes can be observed. Add same-source clearing or a request interface only when the corresponding operation is available.

## Where it fits

The Reset Contract defines the interface and observable behavior. A concrete MCU Adapter implements it using Hardware Definitions. The Core consumes a reference to the implementation. Future Devices will bind the selected Adapter to the Core for the application. This project depends on C++11 standard headers.

Add `include/` to the C++11 include path and start with `<reset/reset_info.hpp>`. The [technical guide](docs/index.md) covers the other public interfaces and integration obligations.

## Generate the API reference

Use Doxygen 1.18.0. From this repository root, create `build/` if it does not exist, then run `doxygen Doxyfile`.

```sh
mkdir -p build
doxygen Doxyfile
```

On PowerShell, use `New-Item -ItemType Directory -Force build` for the first command. Open `build/docs/html/index.html`. Mermaid diagrams render in a browser with access to the Mermaid CDN. GitHub Pages publication runs on published releases and on manual dispatches from `main` once Pages is enabled.
